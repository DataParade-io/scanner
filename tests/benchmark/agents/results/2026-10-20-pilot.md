## Setup and what is fragile

- Pi 0.73.1 (`npm install -g @mariozechner/pi-coding-agent`). GPT-6 Luna is not in Pi's built-in list, so it is added in `~/.pi/agent/models.json` under the `openai` provider: id `gpt-6-luna`, api `openai-responses`, `apiKey: "OPENAI_API_KEY"` (the variable name, Pi reads the value from the environment). Model id confirmed from `GET /v1/models` (`gpt-6-luna`; `gpt-5.6-luna` also exists and was not used).
- Invocation: `pi --offline --model openai/gpt-6-luna --thinking low --mode json --no-session --no-context-files --no-extensions --no-skills --no-prompt-templates -p <assignment>` with stdin closed. Without `--offline` and a closed stdin the first probe hung with no output.
- Tokens: every assistant `message_end` event in `--mode json` carries `usage {input, output, cacheRead, cacheWrite, cost}` per model request. `input` is the uncached part; cached input is `cacheRead`. The harness sums these and prices them from `prices.json` (long-context tier handled per request). Pi's own cost field is recorded as a cross-check; the run notes flag any mismatch (none in this run).
- Evidence matching: scanner evidence is often a few lines off the gold span (for example `app/models.py:1-1` against gold `4-6`), so strict overlap scores the scanner at 0 while same-file matching gives 50%. The two numbers are shown separately.
- Flow gold convention: gold flows are mostly self-flows (`third_party:saas_service->third_party:saas_service`, `asset:database->asset:database`). The agent modelled "app calls Checkr" as `asset:service->third_party:saas_service`, which scores as a miss under the endpoint-kind rule. The assignment mentions self-flows but not that convention; that is a prompt and gold-semantics question, not a harness bug.
- The existing identity-key scorer also gives the scanner 0% on both layers for this packet.
- Pilot packet has only 2 accepted components and 2 accepted flows, so every percentage is on 2 to 5 items. This proves the machinery, not model quality.
- Pi tokens include the system prompt and tool definitions (about 3k input tokens for a trivial prompt).
- Vocabulary (`vocabulary.json`) is interim: types from scanner unions, subTypes from gold. DATAP-740 replaces it.
